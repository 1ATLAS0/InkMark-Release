语法与排版

支持数学公式、图表、表格与代码高亮，可导出 PDF 和 HTML。

数学公式

支持 LaTeX 行内公式与独立公式块，编辑时实时预览。

∇ × E = −∂B / ∂t  ·  ∑k=1n k²

图表绘制

支持通过 Mermaid 语法绘制流程图、时序图与状态图，修改文本即时更新图形。

输入文本 → 解析语法 → 生成图表

表格编辑

支持快捷调整行列与对齐方式，可选单元格自动换行或横向滚动。

功能桌面端移动端 实时渲染✓✓ 横向滚动✓✓

代码块

提供主流编程语言语法高亮、代码一键复制与代码字号独立设置。

// render.ts
const parse = (md) => compile(md);

编辑模式

提供专注模式、打字机模式与源码模式，适应不同写作与校对需求。

非当前编辑段落自动降低对比度
专注模式突出当前段落，打字机模式保持光标居中
支持随时切换至纯文本源码视图

文档导出

支持导出为 PDF 与独立 HTML 文件，保留当前主题样式并支持宽表格跨页排版。

PDF HTML .md

内置主题

包含 39 款浅色与深色主题。点击右侧卡片可在上方编辑器中预览配色效果。

浅色与深色模式

提供多种对比度与色调的预设方案，适应不同光线环境下的阅读与编辑。

实时预览切换

在上方主题按钮悬停预览，点击右侧主题卡片即可切换配色。
